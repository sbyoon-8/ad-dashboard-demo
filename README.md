# 채널 x MMP 성과 대시보드 (데모)

퍼포먼스 마케팅의 **채널 데이터**와 **앱스플라이어(MMP) 데이터**를 조인해 보여주는 Streamlit 대시보드 데모입니다.

> ⚠️ 이 데모의 모든 수치는 **임의로 만든 가상 데이터**이며 실제 광고주 데이터가 아닙니다.

## 화면
- 일별 추이 / 채널별 / 캠페인·소재 / 소재 순위 / 데이터 점검
- 사이드바에서 "가상 데모 데이터로 보기"를 체크하거나 주소 뒤에 `?demo=1`을 붙이면 데모 데이터로 열립니다.
- 본인 CSV(`날짜_channel.csv`, `날짜_appsflyer.csv`)를 직접 업로드해서 볼 수도 있습니다. 업로드한 파일은 세션에서만 쓰이고 저장되지 않습니다.

## 로컬 실행
```
pip install -r requirements.txt
streamlit run app.py
```
